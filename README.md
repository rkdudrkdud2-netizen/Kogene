# qPCR CrossCheck

진단키트의 질환·유전자 표적을 입력하면 교차반응 검토 후보를 제시하고, 매 세션 업로드한 사내 자원 파일과 자동 대조하는 Streamlit 웹 앱입니다.

## 주요 기능

- 장관계/호흡기계 × 세균/바이러스 탭 분류
- 특정 표적 검색 시 직접 연관 후보와 같은 증후군의 세균·바이러스 확장 후보를 함께 제시
- 등록 후보의 정식명과 별칭을 모두 검색 타겟으로 자동 인식해 해당 증후군 패널로 확장
- 등록되지 않은 병원체도 사용자 입력 항목으로 유지하여 사내 자원 대조·작업목록·Excel 결과에 포함
- 업로드 자원에서 검색 병원체와 같은 속·바이러스군의 근연종·형을 자동 선정
- 동일 임상 증후군·검체 범주의 비표적 병원체를 분석 특이도 후보로 자동 확장
- 포괄성(Inclusivity) 후보와 특이도(Exclusivity/Cross-reactivity) 후보를 별도 목록·Excel 시트로 분리
- 근연성 및 임상 관련성에 따라 후보를 `필수`, `권장`, `참고` 우선순위로 정렬
- 장관·호흡기·혈액매개 외에 중추신경계, 발열·매개체, 비뇨생식기, 혈류·상처, 피부·점막 및 동물 병원체 분류 지원
- `선정 범위`로 `표적 직접 연관`과 `증후군 확장`을 명확히 구분
- 각 후보를 `근연종` 또는 `동시감염균`으로 구분
- CSV/XLSX 다중 시트 및 상단 설명행 자동 인식
- RapidFuzz 기반 학명 축약·표기 차이 매칭 (`E. coli` ↔ `Escherichia coli`)
- 보유/미보유 상태, 최적 매칭명, 점수, 관리번호 표시
- 한 추천종에 여러 사내 자원이 매칭되면 전체 관리번호와 보유 자원 수 표시
- 장관계 세균·장관계 바이러스·호흡기계 세균·호흡기계 바이러스를 별도 시트로 구성한 Excel 다운로드
- Excel 전체 셀 가운데 정렬·자동 줄바꿈·테두리·교차 행 음영 및 인쇄 너비 최적화
- 사내 관리번호와 Cat no.를 텍스트 식별자로 보존
- 어두운 탐색 사이드바와 국내외 미생물·바이러스 분양처 검색 페이지
- Single/Multiplex qPCR 공통 시험 작업 목록과 입력 구성 선택
- 시험 작업 목록에 장관계·호흡기계·혈액매개 등 전체 질환군과 세균·바이러스·기생충·진균 유형 표시
- Multiplex 타겟 수(1~20개)에 따른 동적 입력란과 미생물별 관련 입력 표적 병합
- Malaria/Plasmodium 및 Babesia 혈액매개 기생충 교차검증 패널
- 동일 추천종에 매칭된 모든 관리번호의 구매일·원액 용량·누적 사용량·잔량·희석액 튜브·비고 표시
- 희석액 보유, 원액 사용 가능, 희석 필요, 소진, 정보 확인 필요 상태 자동 판정
- 최초 원액 용량과 누적 사용량을 이용한 원액 잔량 불일치 경고

이 포괄 확장 방식은 EHEC에만 적용되는 기능이 아닙니다. 지원하는 모든 장관계 타겟은 장관계 세균·바이러스 전체 패널로, 모든 호흡기계 타겟은 호흡기계 세균·바이러스 전체 패널로 확장됩니다. 서로 다른 증후군의 타겟을 함께 입력하면 두 패널을 합쳐 표시합니다.

## 실행

Python 3.10 이상에서 다음 명령을 실행합니다.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 표시되는 로컬 주소(기본값 `http://localhost:8501`)로 접속합니다.

## 공개 웹사이트로 배포

이 저장소는 Streamlit Community Cloud에 바로 배포할 수 있습니다.

1. GitHub 저장소에 코드를 올립니다.
2. Streamlit Community Cloud에서 새 앱을 생성합니다.
3. 저장소, 브랜치 `main`, 실행 파일 `app.py`를 선택합니다.
4. 배포 후 발급되는 `https://...streamlit.app` 주소를 공유합니다.

공개 배포본에서는 방문자가 별도의 설치 없이 브라우저로 앱을 사용할 수 있습니다.

### Windows에서 파일로 실행

- `qPCR_CrossCheck_START.cmd`를 더블클릭하면 필요한 실행 환경을 확인하고 웹 앱을 시작한 뒤 브라우저를 엽니다.
- 이미 웹 앱이 실행 중이면 해당 앱 프로세스를 안전하게 종료한 뒤 최신 코드로 다시 시작합니다. 이때 기존 웹 세션의 업로드 파일은 다시 업로드해야 합니다.
- `qPCR_CrossCheck_STOP.cmd`를 더블클릭하면 이 폴더의 qPCR CrossCheck 프로세스만 찾아 종료합니다.
- 최초 실행 때는 패키지 설치로 시간이 걸릴 수 있으며 인터넷 연결이 필요합니다.

## 업로드 파일

CSV, XLSX 또는 XLSM 파일을 지원합니다. 열 이름에 `균주명`, `미생물명`, `표준물질 균주명`, `Organism`, `Scientific name` 중 하나가 있어야 합니다. `관리번호`, `Cat no.` 열이 있으면 결과에도 함께 표시합니다. 업로드 파일은 앱이 디스크에 저장하지 않으므로 새 세션마다 다시 업로드해야 합니다.

## Windows 로그인 자동 실행

- `register_autostart.vbs`: 현재 사용자의 시작프로그램 폴더에 바로가기를 등록합니다.
- `remove_autostart.vbs`: 해당 바로가기를 삭제합니다. 이미 실행 중인 웹 앱은 종료하지 않으며, 해제 결과는 다음 Windows 로그인부터 적용됩니다.
- 각 스크립트는 등록·삭제 후 바로가기의 실제 존재 여부를 다시 확인합니다.
- 웹 앱 자체를 즉시 종료하려면 `qPCR_CrossCheck_STOP.cmd`를 사용합니다.

> 후보 목록은 시험 설계용 참고 자료이며 특정 키트의 교차반응을 확정하지 않습니다. 최종 검증 패널은 서열 분석, 위험평가 및 적용 규정에 따라 확정해야 합니다.
> 자동 생성 특이도 목록은 근연성·증후군·검체 범주 기반의 후보입니다. 실제 분석 특이도와 교차반응 여부는 프라이머·프로브 서열의 in-silico 분석과 실험 결과로 판정해야 합니다.
